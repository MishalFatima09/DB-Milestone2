# TravelEase 🧳

**TravelEase** is a Windows Forms application built in C# for managing travel bookings efficiently. It allows users to handle trip scheduling, customer details, hotel, transport, and guide allocations in an intuitive, form-based interface.

## ✨ Features

- Add, update, and delete travel bookings
- Assign hotel, transport, and guide services to customers
- View, manage, and filter trips
- Integrated dropdowns for easy service selection
- Connected to a backend SQL database for persistent storage

## 🛠 Tech Stack

- C# (.NET Framework, WinForms)
- Microsoft SQL Server
- ADO.NET (for database operations)
- Visual Studio (IDE)

## 🚀 Getting Started

### Prerequisites
